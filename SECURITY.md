# Security

Token Yugong reads usage files on your computer and keeps everything there: no account, no analytics, no telemetry.
What it reads, what it sends (only the update check and, if you paste a key, the OpenAI or DeepSeek API) and how an
update is checked before it replaces the app are listed in the README ([Updates](README.md#updates),
[Privacy](README.md#privacy)).

## Supported versions

Security fixes go into the latest release only. Update from the app's Update row, with
`brew upgrade --cask s3onghyun/tap/token-yugong`, or from the
[latest release](https://github.com/s3onghyun/token-yugong/releases/latest) before reporting. The Linux and Windows
desktop builds are betas.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through the
[security advisory form](https://github.com/s3onghyun/token-yugong/security/advisories/new)
(**Security → Report a vulnerability**). Include the version, the platform and the steps to reproduce.
If the form is not available to you, write to s3onghyun.hong@gmail.com.
